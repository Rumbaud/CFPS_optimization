# CFPS_optimization

cell-free protein synthesis (CFPS) optimization for best performance

The project aims to develop high expression and low cost CFPS in E. coli cell-free extracts (CFEs). We use the approach of Cheemeng Tan's group
and make CFEs from a consortium of E. coli strains, each over-expressing different translation factors, grown together as a single culture. We try to
increase the expression of this consortium by adding novel strains, over-expressing enzymes that are involved in pyrophosphate degradation, NTP regeneration. 
Main publication: https://www.nature.com/articles/s41467-020-16900-7#Sec8

**Status:** in progress — started January, 2025
**Author:** Rokas Grigaitis, Pausch group, Vilnius University


## Layout

```
data/
  raw/          plate-reader exports, untouched
  processed/    cleaned data written by scripts/
notebooks/      Quarto (.qmd) analyses
scripts/        R helpers — blank subtraction, reordering, formatting
outputs/        rendered reports and figures (NOT tracked in git)
renv/           package library (not tracked)
renv.lock       exact package versions
_quarto.yml     project-wide Quarto settings
```

`outputs/` is regenerated by rendering the notebooks, so it isn't in
the repo.

## Running it

```r
renv::restore()        # install the package versions this project uses
```

Then render the notebooks in `notebooks/`, or in the Terminal:

```bash
quarto render
```

Rendered HTML lands in `outputs/`.

## Analysis decisions

- Blanks: CFPS reactions without GFP plasmid
- Exclusions: all experiments are done excluding the outside layer of wells
- Replicates: technical - reactions from the same CFE batch, biological - reactions from the CFE of the same strain, but different batch
